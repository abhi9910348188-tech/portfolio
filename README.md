# Abhishek Bharti: The Career Sprint

An interactive 3D portfolio game built with Three.js. Run the career race, jump the skill hurdles, unlock projects and reach the finish line.

**Live site:** https://abhi9910348188-tech.github.io/portfolio/

## Run locally
Open `index.html` in a browser. No build step and no dependencies to install.

## Edit the content
All text comes from the `PORTFOLIO` object near the top of the script in `index.html`: skills, projects, experience, contributions and contact links.

## Tech
Three.js (r128), WebGL, Web Audio, vanilla JavaScript, HTML and CSS.
